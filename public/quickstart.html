Two players in one room, in 10 minutes

Pick your engine. Each tab has the same five steps: get a free test project and key, install, connect, join a room, and see a second player. Under every step is what you should see when it worked. Nothing here costs anything: test projects and test rooms are free.

Plain JavaScript on Node 22 or newer (any computer where node -v works). Two terminals play two players.

  1. Get a free test project key

    Open the dashboard and sign in (no account yet? The sign-in page makes one, free). Type a name such as My first game and press Make my first project: its id (my-first-game) is what your code passes as project. Then open Account, press Make my API key and copy it now: it is shown once. Put it in your shell, never in your code or git.

    export HAWKESGEN_KEY=paste_your_key_here          # macOS, Linux
$env:HAWKESGEN_KEY = "paste_your_key_here"        # Windows PowerShell
    You should see: the project page with its id and tabs for Rooms, Tickets, Settings and Connect, and on Account the key once. Afterwards Account only shows how it starts: 
    Your key starts hk_live_ab12…, made today, not used yet

  2. Install

    In an empty folder:

    npm init -y
npm install @hawkesgen/net
    You should see: 
    added 1 package, and audited 2 packages in 1s
found 0 vulnerabilities

  3. Connect

    Save this as first-room.mjs. It asks for a ticket with your key and opens the connection. Run it with a name: node first-room.mjs Ada.

    import { join } from '@hawkesgen/net';

const name = process.argv[2] ?? 'Ada';
const me = await join('first-room', { project: 'my-first-game', key: process.env.HAWKESGEN_KEY, name });
console.log(`${name} is in "first-room" on the ${me.transport}`);
await me.leave();
    You should see: 
    Ada is in "first-room" on the relay
    If it fails, the error carries a code that /docs/errors explains: a 401 means the key is missing or was replaced (step 1); a 403 or "unknown project" means project isn't your project's id.

  4. Join a room and listen

    Replace the file with this: Ada now waits in first-room, greets everyone who is there or arrives, and prints what she hears. She stays 30 seconds, then leaves by herself.

    import { join } from '@hawkesgen/net';

const name = process.argv[2] ?? 'Ada';
const me = await join('first-room', { project: 'my-first-game', key: process.env.HAWKESGEN_KEY, name });
console.log(`${name} is in "first-room" on the ${me.transport}`);

const greet = (peer) => { console.log(`${name} sees ${peer.name} arrive`); me.send('chat', `hello ${peer.name}`); };
for (const peer of me.peers.values()) if (peer.id !== me.id) greet(peer);   // whoever was here before you
me.when('peer:join', greet);                                              // whoever comes after
me.on('chat', (text, from) => console.log(`${name} heard ${from.name}: ${text}`));

await new Promise((r) => setTimeout(r, 30000));
await me.leave();
    node first-room.mjs Ada
    You should see the same line, then quiet while she waits. On the dashboard, your project's Rooms tab lists first-room with 1 player: 
    Ada is in "first-room" on the relay

  5. See the second player

    Within those 30 seconds, open a second terminal in the same folder (with the key set there too) and run Bob:

    node first-room.mjs Bob
    You should see in Ada's terminal (the last two lines can come in either order): 
    Ada is in "first-room" on the relay
Ada sees Bob arrive
Ada heard Bob: hello Ada
    and in Bob's: 
    Bob is in "first-room" on the relay
Bob sees Ada arrive
Bob heard Ada: hello Bob
    Two clients, one room, messages both ways: that's multiplayer.

A Babylon.js scene in the browser, with a bundler (Vite, webpack) or a plain page. Your own machine (localhost) always joins your project's free test rooms, so a web page needs no key in it.

  1. Get a free test project key

    Open the dashboard, sign in (free), type a name such as My first game and press Make my first project. Its id (my-first-game) is your project. A web page on localhost needs nothing more; keep a key for scripts and bots (Account > Make my API key, shown once):

    export HAWKESGEN_KEY=paste_your_key_here          # macOS, Linux
$env:HAWKESGEN_KEY = "paste_your_key_here"        # Windows PowerShell
    You should see: the project page with its id, and tabs for Rooms, Tickets, Settings and Connect. Rooms is empty.
    The project page: its id, four tabs, and an empty Rooms list.

  2. Install

    npm install @babylonjs/core @hawkesgen/net-babylon
    You should see: 
    added 3 packages, and audited 4 packages in 4s
found 0 vulnerabilities

  3. Connect

    In your scene code, with your player's mesh, start multiplayer. It asks for a ticket and opens the connection by itself:

    import * as BABYLON from '@babylonjs/core';
import { multiplayer } from '@hawkesgen/net-babylon';

const mp = multiplayer(scene, {
  babylon: BABYLON, project: 'my-first-game', name: 'Ada',
  player: playerMesh, liveHosts: ['mygame.com'],
});
mp.when('status', ({ status }) => console.log('status: ' + status));
    You should see in the browser console, with the page served from localhost: 
    status: online

  4. Join a room

    A room is an area. Add area: 'first-room' to the options (the default is 'lobby') and say who arrives:

    const mp = multiplayer(scene, {
  babylon: BABYLON, project: 'my-first-game', name: 'Ada',
  player: playerMesh, area: 'first-room', liveHosts: ['mygame.com'],
});
mp.when('status', ({ status }) => console.log('status: ' + status));
mp.when('peer:join', (p) => console.log(p.name + ' arrived'));
    You should see: the same console line, and on the dashboard the project's Rooms tab lists t-first-room with 1 player (the t- marks a free test room): 
    status: online

  5. See the second player

    Open the same page in a second browser tab. Give it a different name if you like; the default avatar is a capsule with the name over it. With Vite, run the page and open its address twice:

    npx vite          # then open http://localhost:5173 in two tabs
    You should see: in the first tab's console, and a capsule in the scene that moves when the other tab's player moves: 
    Player 42 arrived
    Your ball, and the other player as a green capsule with their name over it.

Unity 2021 or newer. The Editor joins your project's test rooms with no key; a web page on localhost is the second player.

  1. Get a free test project key

    Open the dashboard, sign in (free), type a name such as My first game and press Make my first project. Its id (my-first-game) is your project. The Editor needs nothing more; keep a key for scripts and servers (Account > Make my API key, shown once):

    export HAWKESGEN_KEY=paste_your_key_here          # macOS, Linux
$env:HAWKESGEN_KEY = "paste_your_key_here"        # Windows PowerShell
    You should see: the project page with its id, and tabs for Rooms, Tickets, Settings and Connect. Rooms is empty.
    The project page: its id, four tabs, and an empty Rooms list.

  2. Install

    Package Manager > + > Add package from tarball, and choose com.hawkes.net.tgz (or use the git URL on the dashboard's Docs).

    https://net.hawkesgen.ai/sdk/com.hawkes.net.tgz
    You should see: Hawkes Net in the Package Manager's In Project list, and no red in the Console.
    Package Manager, In Project: Hawkes Net is there.

  3. Connect

    Put this on any GameObject and press Play. The lobby asks for a ticket and opens the connection when you join; its status says when it's up.

    using UnityEngine;
using Hawkes;

public class FirstRoom : MonoBehaviour {
    HawkesNetLobby lobby;
    void Start() {
        lobby = new HawkesNetLobby(new HawkesNetOptions { project = "my-first-game", name = "Ada" }, "mygame.com");
        lobby.StatusChanged += (s) => Debug.Log("status: " + s);
        lobby.Join("lobby");
    }
    void OnDestroy() { lobby?.Leave(); }
}
    You should see in the Console: 
    status: online

  4. Join a room

    Join first-room instead of lobby, and log who arrives:

            lobby.PeerJoined += (id, who) => Debug.Log(who + " arrived");
        lobby.Join("first-room");
    You should see: the same Console line, and on the dashboard the project's Rooms tab lists t-first-room with 1 player: 
    status: online

  5. See the second player

    The second player can be a browser tab. Save this as index.html, serve the folder (npx serve .; the page must be on localhost) and open it while the Editor plays:

    <script type="module">
import { lobby } from 'https://net.hawkesgen.ai/sdk/hawkes-net@1.mjs';

const lob = lobby({ project: 'my-first-game', liveHosts: ['mygame.com'], name: 'Bob' });
lob.when('peer:join', (p) => console.log(p.name + ' arrived'));
lob.join('first-room');
</script>
    You should see: the Console prints the first line, and the browser console the second: a Unity player and a browser player in one room. 
    Bob arrived
Ada arrived
    The Rooms tab: t-first-room with two players.

What next

Move something

net.pose([x, y, z], yaw) every frame and net.onPose for everyone else: that's avatars. The demo does it with dots.

Put it online

List your game's sites in the project's Settings (credits or a plan) and pages there join with no key. Servers ask for tickets with the key. See a game with a server.

Something broke

Every error has a stable code and a fix: /docs/errors. Or write support@hawkesgen.ai.
