Two players in one room, in 10 minutes

You'll make a free test project and an API key, then put two clients in the same room and watch them hear each other. Every step says what you should see when it worked. Nothing here costs anything: test projects and test rooms are free.

  1. Sign in (1 minute)

    Open the dashboard and sign in with your hawkesgames.com account. No account yet? The sign-in page makes one, free.

    You should see: the dashboard's Projects page with your name at the top right, and "Put your first game online" if you have no project yet.

  2. Make a test project (1 minute)

    A project is your game's identity on Hawkes Net. Type a name, for example My first game, and press Make my first project. The project's id is made from the name (my-first-game); it is what your code passes as project.

    A free account is enough: your project builds and tests on localhost and from keyed scripts, in test rooms, with up to 3 rooms and 8 players a room. Putting your game on your own site needs credits; that's step "What next".

    You should see: the project's page with its id (my-first-game), and tabs for Rooms, Tickets, Settings and Connect. Rooms is empty.

  3. Make an API key (1 minute)

    Scripts, bots and servers have no website to be recognised by, so they use a key. Open Account and press Make my API key. The key is shown once: copy it now.

    Put it in your shell. Keep it out of your code and out of git.

    export HAWKESGEN_KEY=paste_your_key_here          # macOS, Linux
$env:HAWKESGEN_KEY = "paste_your_key_here"        # Windows PowerShell
    You should see: after you press the button, the whole key once; afterwards the Account page only shows its first characters ("Your key starts …, made today, not used yet"). Making a new key stops the old one at once.

  4. Join your first room, twice (3 minutes)

    You need Node 22 or newer (any computer that runs node -v will do). In an empty folder:

    npm init -y
npm install @hawkesgen/net

    Save this as first-room.mjs. It plays two players, Ada and Bob, who join first-room and say hello to each other:

    import { join } from '@hawkesgen/net';

const opts = { project: 'my-first-game', key: process.env.HAWKESGEN_KEY };

const ada = await join('first-room', { ...opts, name: 'Ada' });
console.log(`Ada is in "first-room" on the ${ada.transport}`);
ada.when('peer:join', (peer) => console.log(`Ada sees ${peer.name} arrive`));
ada.on('chat', (text, from) => console.log(`Ada heard ${from.name}: ${text}`));

const bob = await join('first-room', { ...opts, name: 'Bob' });
console.log(`Bob is in "first-room" on the ${bob.transport}`);
bob.on('chat', (text, from) => console.log(`Bob heard ${from.name}: ${text}`));

ada.send('chat', 'hello Bob');
bob.send('chat', 'hello Ada');

await new Promise((r) => setTimeout(r, 500));
await ada.leave();
await bob.leave();
    node first-room.mjs
    You should see (the last three lines can come in either order): 
    Ada is in "first-room" on the relay
Bob is in "first-room" on the relay
Ada sees Bob arrive
Bob heard Ada: hello Bob
Ada heard Bob: hello Ada
    Then the script ends by itself. Two clients, one room, messages both ways: that's multiplayer.

    If it fails, the error carries a code that /docs/errors explains. The usual ones: hawkes-net: ticket refused (401) means the key is missing or was replaced (step 3); a 403 or "unknown project" means project isn't your project's id (step 2).

  5. The same in a browser (2 minutes)

    Web pages need no key. Your own machine (localhost) always joins your project's test rooms. Save this as index.html and serve the folder, for example npx serve . (it's the page that must be on localhost; opening the file straight from disk won't do):

    <script type="module">
import { lobby } from 'https://net.hawkesgen.ai/sdk/hawkes-net@1.mjs';

const lob = lobby({ project: 'my-first-game', liveHosts: ['mygame.com'], name: 'Player ' + Math.floor(Math.random() * 100) });
const log = (t) => document.body.append(Object.assign(document.createElement('p'), { textContent: t }));

lob.when('status', ({ status }) => log('status: ' + status));
lob.when('peer:join', (p) => log(p.name + ' arrived'));
lob.on('chat', (text, from) => log(from.name + ': ' + text));
lob.join('level-1');
addEventListener('click', () => lob.send('chat', 'hello!'));   // click the page to say hello
</script>
<p>Click anywhere to say hello.</p>

    Open http://localhost:3000 (the address serve prints) in two tabs, then click in one.

    You should see: in each tab status: online; the first tab then adds Player 42 arrived (a different number) when the second opens; a click in either tab puts Player 42: hello! in both. Reload one tab and it rejoins by itself. Then look at your project's Rooms tab on the dashboard: t-level-1 is listed with its two players (the t- marks a test room, free and apart from your real players).

  6. Babylon.js and Unity (the same room)

    Babylon.js. npm install @babylonjs/core @hawkesgen/net-babylon, then in your scene, with your player's mesh:

    import * as BABYLON from '@babylonjs/core';
import { multiplayer } from '@hawkesgen/net-babylon';

const mp = multiplayer(scene, { babylon: BABYLON, project: 'my-first-game', name: 'Ada', player: playerMesh, liveHosts: ['mygame.com'] });
    You should see: run your scene from localhost in two tabs; each tab shows the other player as a moving avatar, and the Rooms tab lists the room.

    Unity. Package Manager > + > Add package from tarball, choosing com.hawkes.net.tgz (or the git URL on the dashboard's Docs). Put this on any GameObject and press Play:

    using UnityEngine;
using Hawkes;

public class FirstRoom : MonoBehaviour {
    HawkesNetLobby lobby;
    void Start() {
        lobby = new HawkesNetLobby(new HawkesNetOptions { project = "my-first-game", name = "Ada" }, "mygame.com");
        lobby.PeerJoined += (id, name) => Debug.Log($"{name} arrived");
        lobby.Join("level-1");
    }
    void OnDestroy() { lobby?.Leave(); }
}
    You should see: in the Editor, with the web page from step 5 open in a tab, the Console prints Player 42 arrived and the web tab prints Ada arrived: a Unity player and a browser player in one room. (The Editor joins your project's test rooms with no key.)

    The exact namespace and options are in the package's readme (hawkesnet-unity); the dashboard's Docs page has the same code.

What next

Move something

net.pose([x, y, z], yaw) every frame and net.onPose for everyone else: that's avatars. The demo does it with dots.

Put it online

List your game's sites in the project's Settings (credits or a plan) and pages there join with no key. Servers ask for tickets with the key. See a game with a server.

Something broke

Every error has a stable code and a fix: /docs/errors. Or write support@hawkesgen.ai.
